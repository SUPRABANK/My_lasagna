# ร้านลาซานญ่า — แอปคิดยอด & เช็คสต๊อก 

## หลักการทำงาน (สต๊อกบ้าน ↔ งานขาย)

ของใน **คลัง (สต๊อกบ้าน)** กับของใน **ร้าน (งานขายของพนักงาน)** เป็นคนละก้อนกัน:

1. **เถ้าแก่** สร้าง **งานขาย** — เลือกพนักงาน + สถานที่ขาย + จำนวนสินค้า → ระบบหักจากคลังอัตโนมัติ
2. **พนักงานขาย** เห็นรายการของที่ตัวเองถืออยู่บนหน้า **“ร้านของฉัน”**
3. ตอนปิดร้าน พนักงาน **นับของเหลือ** แล้วส่งยอดให้เถ้าแก่ → ของเหลือจะ **คืนเข้าคลัง** อัตโนมัติ
4. **เถ้าแก่** เห็นยอดขาย (ส่ง − เหลือ) ที่พนักงานส่งมา แล้ว **กรอกแค่เงินที่ได้รับ** (เงินสด / QR / คนละครึ่ง) → ระบบสรุป ขาด/เกิน

## ฟีเจอร์หลัก

| ฟีเจอร์ | รายละเอียด |
|---|---|
| สิทธิ 3 ระดับ | **เถ้าแก่ → พนักงานครัว → พนักงานขาย** (หลายคน) ด้วยรหัส PIN |
| สต๊อกคลัง | สินค้า 8 ชนิด แก้ไขได้เฉพาะ เถ้าแก่ / พนักงานครัว |
| สร้างงานขาย | เถ้าแก่แจกของให้แต่ละร้าน/ตลาด หักจากคลังอัตโนมัติ |
| ร้านของฉัน | พนักงานเห็นของที่ตัวเองถืออยู่ |
| นับของส่งปิดยอด | พนักงานนับของเหลือส่งเถ้าแก่ ของเหลือคืนคลังอัตโนมัติ |
| ปิดยอดเงิน | เถ้าแก่กรอกแค่เงินที่ได้รับ เทียบกับยอดขาย สรุป ขาด/เกิน |

| ตั้งค่า | จัดการพนักงาน, แก้รหัส, ราคา, สำรอง/นำเข้าข้อมูล (เฉพาะเถ้าแก่) |

## ขั้นตอนใช้งานประจำวัน

**ตอนเช้า (เถ้าแก่):**
1. เข้า **สต๊อก** ตรวจ/ปรับจำนวนในคลังให้ตรงจริง
2. เข้า **งานขาย → สร้างงานใหม่** เลือกพนักงาน ใส่สถานที่ (เช่น ตลาดรวมใจ) และจำนวนสินค้าที่ให้ไป → ของจะถูกหักจากคลัง

**ตอนขาย (พนักงาน):**
- เปิดแอป เลือกชื่อตัวเอง ใส่ PIN → เห็นงานที่กำลังขายและของที่ถืออยู่ที่ **ร้านของฉัน**

**ตอนปิดร้าน (พนักงาน):**
- ที่ **ร้านของฉัน** กด **“นับของเหลือ / ส่งปิดยอด”** → นับของที่เหลือจริง ส่งให้เถ้าแก่ → ของเหลือคืนเข้าคลังอัตโนมัติ

**ตอนปิดยอดเงิน (เถ้าแก่):**
- เข้า **งานขาย** → งานที่รอปิดยอดจะขึ้นมา → กด **“ปิดยอด (กรอกเงิน)”** → กรอกแค่ **เงินสด / QR / คนละครึ่ง** → ระบบสรุป ขายเท่าไหร่ ควรได้เงินเท่าไหร่ ขาด/เกินเท่าไหร่ → ยืนยัน

## ไฟล์ในโปรเจกต์

| `index.html` | โครงหน้าแอป |

| `app.js` | ตรรกะทั้งหมด (ข้อมูล, สิทธิ, งานขาย, คำนวณ) |

| `server.js` / `start.bat` | เซิร์ฟเวอร์ทดสอบแบบไม่มี dependency |

| `tools/gen_icons.py` | สคริปต์สร้างไอคอน |
