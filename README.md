# ร้านลาซานญ่า — แอปคิดยอด & เช็คสต๊อก 📱

แอปมือถือ (PWA) สำหรับร้านอาหาร ใช้บนมือถือ/แท็บเล็ต Android โดยติดตั้งลงหน้าจอหลัก
ใช้งานออฟไลน์ เก็บข้อมูลในเครื่อง ไม่ต้องใช้เน็ตหรือเซิร์ฟเวอร์

## หลักการทำงาน (สต๊อกบ้าน ↔ งานขาย)

ของใน **คลัง (สต๊อกบ้าน)** กับของใน **ร้าน (งานขายของพนักงาน)** เป็นคนละก้อนกัน:

1. **เถ้าแก่** สร้าง **งานขาย** — เลือกพนักงาน + สถานที่ขาย + จำนวนสินค้า → ระบบหักจากคลังอัตโนมัติ
2. **พนักงานขาย** เห็นรายการของที่ตัวเองถืออยู่บนหน้า **“ร้านของฉัน”**
3. ตอนปิดร้าน พนักงาน **นับของเหลือ** แล้วส่งยอดให้เถ้าแก่ → ของเหลือจะ **คืนเข้าคลัง** อัตโนมัติ
4. **เถ้าแก่** เห็นยอดขาย (ส่ง − เหลือ) ที่พนักงานส่งมา แล้ว **กรอกแค่เงินที่ได้รับ** (เงินสด / QR / คนละครึ่ง) → ระบบสรุป ขาด/เกิน

## วิธีเปิดใช้งาน

### วิธีที่ 1 — บนคอมพิวเตอร์เครื่องนี้ (ทดสอบ)

1. ดับเบิลคลิกไฟล์ `start.bat` (หรือเปิด Terminal แล้วพิมพ์ `node server.js`)
2. เปิดเบราว์เซอร์ไปที่ **http://localhost:8080**

### วิธีที่ 2 — ใช้บนมือถือ Android (ใช้งานจริง)

1. ต่อคอมพิวเตอร์กับมือถือใน Wi-Fi เดียวกัน
2. รัน `start.bat` บนคอมพิวเตอร์ แล้วดูเลข IP ของคอมพิวเตอร์ (พิมพ์ `ipconfig` แล้วดูค่า IPv4 เช่น `192.168.1.23`)
3. เปิด Chrome/Edge บนมือถือ ไปที่ `http://<IP ของคอม>:8080`
4. แตะเมนู ⋮ → **“เพิ่มไปที่หน้าจอหลัก”** → ได้ไอคอนแอปเต็มจอเหมือนแอปจริง

> 💡 ใช้ได้ตลอดแม้คอมปิด ให้ deploy ไฟล์นี้ขึ้นโฮสต์ฟรี เช่น GitHub Pages / Netlify / Vercel แล้วเปิด URL นั้นบนมือถือ
>
> ⚠️ การติดตั้งเป็นแอปเต็มจอ (PWA) ต้องเปิดผ่าน **HTTPS** หรือ **localhost** เท่านั้น
> — เปิดผ่าน IP ในวง LAN (http://192.168.x.x) จะใช้ในเบราว์เซอร์ได้ แต่เมนู “เพิ่มไปที่หน้าจอหลัก” อาจไม่ขึ้น
> แนะนำ deploy ขึ้นโฮสต์ฟรีที่มี HTTPS สำหรับใช้งานจริงระยะยาว

## ขั้นตอนใช้งานประจำวัน

**ตอนเช้า (เถ้าแก่):**
1. เข้า **สต๊อก** ตรวจ/ปรับจำนวนในคลังให้ตรงจริง
2. เข้า **งานขาย → สร้างงานใหม่** เลือกพนักงาน ใส่สถานที่ (เช่น ตลาดรวมใจ) และจำนวนสินค้าที่ให้ไป → ของจะถูกหักจากคลัง

**ตอนขาย (พนักงาน):**
- เปิดแอป เลือกชื่อตัวเอง ใส่ PIN → เห็นงานที่กำลังขายและของที่ถืออยู่ที่ **ร้านของฉัน**

**ตอนปิดร้าน (พนักงาน):**
- ที่ **ร้านของฉัน** กด **“นับของเหลือ / ส่งปิดยอด”** → นับของที่เหลือจริง ส่งให้เถ้าแก่ → ของเหลือคืนเข้าคลังอัตโนมัติ

**ตอนปิดยอดเงิน (เถ้าแก่):**
- เข้า **งานขาย** → งานที่รอปิดยอดจะขึ้นมา → กด **“ปิดยอด (กรอกเงิน)”** → กรอกแค่ **เงินสด / QR / คนละครึ่ง** → ระบบสรุป ขายเท่าไหร่ ควรได้เงินเท่าไหร่ ขาด/เกินเท่าไหร่ → ยืนยัน

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าแอป |
| `styles.css` | สไตล์/ธีมสี |
| `app.js` | ตรรกะทั้งหมด (ข้อมูล, สิทธิ, งานขาย, คำนวณ) |
| `manifest.webmanifest` + `sw.js` | ทำให้เป็น PWA ติดตั้งได้ + ใช้ได้ออฟไลน์ |
| `server.js` / `start.bat` | เซิร์ฟเวอร์ทดสอบแบบไม่มี dependency |
| `icons/` | ไอคอนแอป (สร้างจาก `logo.jpg`) |
| `tools/gen_icons.py` | สคริปต์สร้างไอคอน |

## สำรองข้อมูล

- เข้า **ตั้งค่า → สำรองข้อมูล** เพื่อดาวน์โหลดไฟล์ `.json`
- ย้ายเครื่อง/กู้คืน: **ตั้งค่า → นำเข้าข้อมูล** เลือกไฟล์ที่สำรองไว้

⚠️ ข้อมูลเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น ๆ — ควรสำรองข้อมูลเป็นประจำ
